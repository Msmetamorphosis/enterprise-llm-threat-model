# Malicious Input Corpus

Synthetic pasted-content payloads used by the scenario 3 (accidental
self-injection) trials. Every file is fabricated for this project. None
of these represent real client emails or newsletters.

The corpus lives here rather than in the main data folders so that
retrieval treats it as external, untrusted content that the advisor
brings into the session by pasting, not as documents the retriever
should surface on its own.
